## My Calculator

A simple calculator built using HTML, CSS and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear the display

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open the index.html file in a web browser.

Git recovery practice: temporary changes

Added Scientific Operations:
Percentage (%): Converts display value into a decimal percentage.
Sign Toggle (+/-): Inverts current input between positive & negative.
Square Root (√): Computes square root of current display value.
Exponentiation (x² or ^): Allows square or custom power calculations.
